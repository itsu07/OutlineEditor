# OutlineWriter Mobile - 原稿執筆特化アウトラインエディター（モバイル/PWA版）

OutlineWriter Mobileは、階層的なアウトライン機能を持つ、原稿執筆に特化したWebアプリケーションのモバイル/PWA版です。小説、論文、レポート、ブログ記事などの執筆において構造的な文章作成をサポートします。スマートフォンでの操作に最適化されており、ホーム画面への追加（PWAインストール）とオフライン動作に対応しています。

## 特徴

- **階層的アウトライン構造**: 項目の追加・インデント・アウトデント・上下移動・削除
- **見出しの自動判定**: 子項目を持つ項目は自動的に見出しとして区別表示
- **展開/折り畳み**: 子項目の表示状態を項目ごと・一括で切り替え
- **検索機能**: Ctrl+F または 🔍ボタンで全項目を対象に検索
- **パンくずリスト**: 現在編集中の項目の階層位置を表示
- **リアルタイム文字数カウント**: 現在項目と全体の文字数表示
- **アンドゥ・リドゥ機能**: 操作履歴を最大50件記録（記録はデバウンス処理）
- **自動保存**: 編集の約800ms後にローカルストレージへ自動保存＋手動保存
- **バックアップシステム**: 5分間隔の自動バックアップと手動バックアップ・復元（最大10件保持）
- **インポート・エクスポート**: JSON / Markdown の読み込み、JSON / Markdown / テキストの出力（ファイル名指定可）
- **モバイルUI**: ハンバーガーメニュー式サイドバー、スワイプジェスチャー、下部ツールバー（表示/非表示切替）
- **PWA対応**: ホーム画面へのインストール、Service Workerによるオフライン動作
- **Google Drive同期**: OAuth（Google Identity Services）によるDriveへの保存・読み込み

## システム要件

- モダンブラウザ（Chrome, Firefox, Safari, Edge）
- JavaScript有効
- ローカルストレージ対応

## 起動方法

1. 上記のファイルを同一フォルダに配置
2. `index.html` をブラウザで開く

**注意**: Google Drive同期を使う場合は、`file://` ではなく http(s) サーバー経由で開く必要があります（後述）。アウトライン編集・保存・バックアップなどDrive以外の機能は `file://` やオフラインでも動作します。

簡易サーバーの例:

```
python -m http.server 8000
# → http://localhost:8000/index.html
```

### サイドバー（ハンバーガーメニュー）

- Google API診断

### エディター領域

- **内容入力欄**: 項目の本文を編集
- **文字数表示**: 現在項目と全体の文字数

### 下部ツールバー
- 項目追加 / インデント / アウトデント / 上へ移動 / 下へ移動 / 削除

## 基本操作

### 項目の作成・編集
1. 「項目追加」で新しい項目を作成
2. アウトラインの項目をタップして選択
3. エディター領域でタイトル・本文を編集（自動保存されます）

### 階層構造の操作
- **インデント**: 選択項目を1つ上の項目の子にする
- **アウトデント**: 選択項目を親と同じレベルに上げる
- **上へ/下へ移動**: 同じ階層内で項目を並び替える

### 見出し
- 子項目を持つ項目は自動的に見出し扱いになります（Markdown出力では `#` 見出し、子のない項目はリスト行）

### 折り畳み・展開
- 子項目がある項目の「▼」「▶」をタップ
- 一括展開/折り畳みも可能

### 検索
- 🔍ボタンまたは Ctrl+F で検索バーを表示
- 入力に応じてリアルタイムに項目を絞り込み
- Escape または ✕ で検索を閉じる

### スワイプジェスチャー
- **画面左端から右にスワイプ**: サイドバーを開く
- **左にスワイプ**: サイドバーを閉じる

### アンドゥ・リドゥ
- **Ctrl+Z**: 元に戻す
- **Ctrl+Y / Ctrl+Shift+Z**: やり直し
- ツールバーのボタンでも操作可能（履歴は最大50件）

### バックアップ・復元
1. **手動バックアップ**: メニューの「バックアップ」で現在の状態を保存
2. **自動バックアップ**: 5分間隔で自動作成
3. **復元**: 「復元」でバックアップ一覧が表示され、番号を入力して選択
4. **保持数**: 最大10件（古いものから自動削除）

### インポート・エクスポート
**読み込み対応形式:**
- **JSON**: OutlineWriter内部形式（完全復元）
- **Markdown**: `#` 見出しレベルによる階層構造を復元（エクスポート時の階層コメントにも対応）

**出力対応形式:**
- **JSON** / **Markdown** / **テキスト**
- 出力時にファイル名を入力できます（キャンセルで中止）

## Google Drive同期

Google Drive（`drive.file` スコープ）にアウトラインデータをJSONファイルとして保存・読み込みできます。

### セットアップ
1. Google Cloud Console でプロジェクトを作成
2. Google Drive API を有効化
3. OAuth 2.0 クライアントID（ウェブアプリケーション）を作成
4. 「承認済みのJavaScriptの生成元」にアプリを配信するオリジンを追加
5. `config.js` の `CLIENT_ID` に取得したクライアントIDを設定

APIキーは不要です。認証には Google Identity Services（GIS）を使用します。

### 使い方
1. メニューの「Google Drive設定」からログイン
2. 既存ファイルの選択、または新規ファイルの作成
3. 「同期」ダイアログからアップロード/ダウンロード
4. 「自動同期」を有効にすると、起動時にサイレントログイン＋同期を試行します

### 同期先ファイルと表示中の原稿
アプリは次の2つを区別して表示します。

| 表示名 | 意味 | 表示場所 |
|---|---|---|
| **同期先ファイル** | アップロード/ダウンロードの対象となるDriveファイル | メニューの「Drive同期」、Drive設定ダイアログ、同期ダイアログ |
| **表示中の原稿** | いまエディタにある原稿がどこから来たか（例: `Drive: A.json`、`ファイル: foo.md`、`不明（記録なし）`） | Drive設定ダイアログ、同期ダイアログ |

- 既存ファイルを選択しても、ダウンロードするまで表示中の原稿は入れ替わりません。両者が異なる間は「⚠ 表示中の原稿は同期先ファイルから読み込んだものではありません」と表示されます
- Drive設定の「新規作成時のファイル名」は新規作成専用の入力欄です。書き換えても同期先ファイルの名前は変わりません
- Drive側でファイル名を変更した場合、次にDriveへ問い合わせたときに表示が更新されます

### 上書き前の確認
| 操作 | 確認が出る条件 |
|---|---|
| ローカル → Drive（アップロード） | 表示中の原稿が同期先ファイル由来でない／この端末に同期先ファイルとの同期記録がない／前回同期後にDrive側が更新されている |
| Drive → ローカル（ダウンロード） | 表示中の原稿が同期先ファイル由来でない／前回同期後にローカルで編集している |
| 起動時の自動同期 | ローカルに未アップロードの編集があり、かつDrive側も更新されている場合（Drive側に変更がなければ同期をスキップ） |

同期記録（最終同期時刻と、同期時点の原稿内容の指紋）は同期先ファイルごとに保持するため、同期先を切り替えると「未同期」として扱われます。

### 注意事項
- **http(s) 配信が必須**: OAuth の仕様上、`file://` から開いた場合Drive同期は動作しません。OAuthクライアントに登録したオリジン（例: `https://yoursite.com` や `http://localhost:8000`）から配信してください
- **トークン有効期限**: アクセストークンは約1時間で失効します。失効後は再ログインが必要です
- **診断機能**: メニューの「Google API診断」で GIS読み込み / 初期化 / ログイン状態を確認できます（詳細はコンソールに出力）

## PWA（ホーム画面へのインストール）

- http(s) で配信すると Service Worker（`sw.js`）が登録され、アプリシェルがキャッシュされてオフラインでも起動できます
- ブラウザのメニューから「ホーム画面に追加」/「インストール」でアプリとして利用できます
- キャッシュはバージョン管理されており（`outlinewriter-v1`）、更新時は古いキャッシュが自動削除されます

## データ管理

### ローカルストレージのキー
| キー名 | 内容 |
|---|---|
| `outlinewriter-data` | メインのアウトラインデータ |
| `outlinewriter-backups` | バックアップデータ（最大10件） |
| `outlinewriter-drive-config` | Google Drive連携設定（ファイル名・ファイルID・同期設定など） |
| `outlinewriter-data-timestamp` | ローカルデータの最終保存日時 |
| `outlinewriter-data-source` | 表示中の原稿の出どころ（Driveファイル/読み込んだファイル） |
| `outlinewriter-drive-sync-state` | 同期先ファイルごとの同期記録（ファイルID・最終同期時刻・内容の指紋） |
| `toolbar-visible` | 下部ツールバーの表示状態 |

### データ形式

保存されるデータ構造:
```json
{
  "items": [
    {
      "id": 1,
      "title": "項目タイトル",
      "content": "項目の内容",
      "children": [],
      "expanded": true,
      "parentId": null,
      "hierarchyPath": "1",
      "level": 0
    }
  ],
  "nextId": 2
}
```

- `hierarchyPath` / `level` は階層位置を表すフィールドで、Markdownエクスポート時の階層コメントにも利用されます

## トラブルシューティング

### データが消えた場合
1. ブラウザのローカルストレージが削除された可能性があります
2. 「バックアップ」→「復元」で過去のバックアップから復旧を試行
3. Google Drive同期を設定済みなら「ダウンロード」でDrive上のデータを取得

### Google Driveに接続できない場合
1. `file://` で開いていないか確認（http(s) 配信が必要）
2. `config.js` の `CLIENT_ID` が設定されているか確認
3. OAuthクライアントの「承認済みのJavaScriptの生成元」に現在のオリジンが登録されているか確認
4. メニューの「Google API診断」で状態を確認
5. トークン失効（約1時間）の場合は再ログイン

### 動作しない場合
1. JavaScriptが有効になっているか確認
2. ブラウザのコンソールでエラーを確認
3. ファイルが同一フォルダに正しく配置されているか確認

## 開発者向け: 自動テスト

Google Drive同期まわりの動作を Playwright（Chromium）で確認するテストがあります。Google のログイン（GIS）と Drive API はテスト内のフェイクに差し替えるため、Googleアカウントやネットワーク接続は不要です（本物のGoogleとの結合は確認対象外）。

```
npm install
npx playwright install chromium   # 初回のみ（ブラウザ未導入の場合）
npm test
```
